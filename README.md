# Jeremy Glebe — Portfolio

A minimal React portfolio focused on Jeremy's software engineering work,
experience, and contact information.

## Development

```bash
npm install
npm run dev
```

The development site runs at the local URL printed by Vite, normally
`http://localhost:5173`.

## Production build

```bash
npm run build
```

Pushing `main` runs the GitHub Pages workflow and publishes the `dist` build to
`jeremyglebe.com`.
